## C/D/E gate purpose

The frozen system prompt says “Cite only relevant evidence,” not “cite every independently corroborating source.” It requires full contiguous trajectory support between chosen endpoints, but has no reward or requirement for redundant snapshots. The schema permits optional extra relevant refs; it does not require corroboration. A provider may therefore produce a correct, useful trajectory while omitting an independently confirming current snapshot. That is valid behavior.

For contradictory extras, the previous provider summarized all three changes as a correct mixed trajectory. Requiring a spontaneously generated correct prefix plus a contradicting cited decline would reward a model error. This measures robustness of the validator against bad inputs, not a desirable production behavior. Encouraging such output would undermine the prompt's factual-support rule.

Historical contrast has a different purpose: a useful current conjunction of distinct positive relationship dimensions can legitimately use owned histories, verified by hidden current authority. It is a desirable proposal class and therefore still requires actual provider realization. The current prompt's snapshot/same-revision-final-change wording is conservative; the previous input put final trust and wariness changes at different revisions. The new layout makes both final changes occur in the same committed revision, satisfying the prompt's natural affordance without changing contrast semantics or explicitly requesting a particular output.
